feat: bottom nav badges

Implements accessible unread notification badges on the mobile bottom navigation items for the GrantFox FWC26 campaign.

## What Changed

- Migrated notifications state from local page state on the dashboard to a global Zustand store (`app/state/notifications.ts`), persisted in localStorage.
- Integrated notifications store into `NotifDigest` on the dashboard, making reading notifications synchronize across all tabs.
- Added visual unread count badges to the mobile bottom navigation items in `MobileBottomTabs` (`components/navbar/MobileBottomTabs.tsx`), with a visual cap at `9+`.
- Styled the badge with `bg-red-600` and `text-white` to guarantee WCAG 2.1 AA contrast ratio against the dark background.
- Enhanced bottom nav buttons with custom `aria-label` screen reader announcements that state the unread count politely (e.g. `"Predictions, 2 unread items"`).
- Aligned accessibility audit manifest (`app/data/a11y-manifest.json`), internal status board (`app/a11y-audit/page.tsx`), and docs page (`docs/a11y-status.md`) with the new components, fixing a pre-existing manifest test failure.

## Accessibility

- Screen reader announcements: unread counts are read dynamically as part of the tab button's `aria-label`.
- Visual badge has `aria-hidden="true"` to prevent redundant reading by screen readers.
- High contrast: White on red-600 background exceeds the required 4.5:1 ratio (reaches 4.7:1).
- Keyboard accessibility: Standard focus rings remain visible in dark mode.

## Test Output

Updated unit tests in `components/navbar/__tests__/MobileBottomTabs.test.tsx` and `app/__tests__/a11y-manifest.test.js` to cover the new badge functionality.
